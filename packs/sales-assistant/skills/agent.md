# Assistente Comercial — instruções operacionais

Executado pelo motor de roles do AtlasHub-AI-WaaS (`packages/roles`, ROLE-002). O comportamento é determinístico; a IA, quando ativada, só classifica mensagens não reconhecidas e escreve rascunhos sujeitos a aprovação.

## Intenções
- `opt_out`
- `meeting`
- `qualify`
- `unknown` → passagem para uma pessoa

## Limites
- Nunca enviar mensagens, publicar ou assumir compromissos sem aprovação humana.
- Nenhuma comunicação sem consentimento registado; pedidos de remoção são imediatos e definitivos.
